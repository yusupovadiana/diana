# Кино в пяти цветах

Практическое занятие №3: сложный flat-дизайн со сценарным скроллингом.

Задание: https://konoplevdesign.blogspot.com/2026/09/2012-3-flat-c.html

## Что есть в проекте

- Пять фильмов, пять абзацев и пять оригинальных иллюстраций 600 × 600.
- `reel.png` — вращающаяся кинокатушка с настоящим прозрачным фоном.
- Пять цветных вкладок: якоря `#film1` — `#film5`, расширение при наведении и фокусе, отметка текущего раздела.
- Светлый фон на компьютере; на телефоне текст лежит поверх цветной врезки. Для зелёного, синего и красного разделов задан светлый текст.
- Градиент в первом разделе. Разная скорость движения иллюстраций и цветных врезок через Scrollax.
- Три библиотеки преподавателя включены в указанном порядке: jQuery → SmoothScroll → Scrollax → собственный `script.js`.
- Поддержка планшетных размеров, клавиатурной навигации и настройки уменьшения анимации.

## Файлы

`index.html` — самостоятельная страница; `style.css` — оформление; `script.js` — инициализация прокрутки, подсветка меню и адаптация к Blogger.

`blogger.html` — фрагмент для HTML-редактора страницы Blogger со ссылками raw.githack.com на этот репозиторий. Размещается в разделе **Страницы**, не в визуальном редакторе сообщения.

`01-budapest.png` — `05-spirited.png` — иллюстрации. SVG-исходники сохранены рядом. Это иллюстрации по мотивам, а не официальные постеры. Палитры и тексты о цвете — авторская интерпретация.

`create-art.mjs` генерирует PNG из исходных векторных форм через Sharp. Для повторной генерации: `npm install`, затем `npm run art`.

## Проверка локально

Запустить `python3 -m http.server 8085` в каталоге и открыть http://localhost:8085.

Основные правила CSS ограничены `#cinema-story`. При загрузке `script.js` переносит этот блок в `body` и добавляет класс `cinema-page`, чтобы тема Blogger не сужала содержимое. Скрытие оболочки темы действует только на странице с этим блоком.

Scrollax меняет `transform` у элементов с `data-scrollax`. На смартфоне текст остаётся в обычном потоке, движутся врезки и иллюстрации. При `prefers-reduced-motion` анимации отключаются.
